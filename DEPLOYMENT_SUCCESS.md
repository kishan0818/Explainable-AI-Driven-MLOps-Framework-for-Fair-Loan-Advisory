## 🚀 **How to Use the Complete Project:**

### **Option 1: Clone the Complete Project**
```bash
git clone https://github.com/kishan0818/TWXAI_backend.git
cd TWXAI_backend
```

### **Option 2: Use Integration Branch**
```bash
git clone https://github.com/kishan0818/TWXAI_backend.git
cd TWXAI_backend
git checkout integration
```

### **Quick Start:**
```bash
# Setup Backend
cd TWXAI_backend
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
pip install fastapi uvicorn requests

# Setup Frontend
cd ..
npm install

# Start Complete System
start_integrated_system.bat
```
